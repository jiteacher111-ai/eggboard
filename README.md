# 🥚 에그보드 (EggBoard) — 학급 경영 웹페이지

학급 화폐로 칭찬하고, 알에서 부화한 펫을 함께 키우고, 학급 마켓에서 쇼핑하는 학급 경영 도구입니다.
설치나 서버가 필요 없고, `index.html`을 브라우저로 열면 바로 사용할 수 있어요.

## 시작하기

1. `index.html`을 크롬/엣지 등 브라우저로 엽니다. (GitHub Pages에 올려서 써도 돼요.)
2. **⚙️ 설정 → 👩‍🎓 학생**에서 학생 명단을 붙여넣습니다. (`1 김하늘`처럼 한 줄에 한 명)
   - 처음이라면 빈 화면의 **예시 학생으로 체험하기**를 눌러 미리 써 볼 수 있어요.
3. **💼 직업·일급**에서 1인 1역 직업과 일급을 정하고, 학생 탭에서 학생마다 직업을 정해 줍니다.

> 데이터는 **이 브라우저(localStorage)** 에 저장됩니다. 다른 컴퓨터로 옮기거나 대비용으로 **💾 백업**에서 백업 파일을 주기적으로 저장하세요.

## 주요 기능

### 1. 학급 보상 (일급 + 추가 보상 + 차감)
- **💰 오늘 일급 지급**: 직업별 일급(직업이 없으면 기본 일급)을 한 번에 지급합니다. 결석생은 체크를 해제하면 되고, 오늘 이미 받은 학생은 표시되어 중복 지급을 막아 줍니다.
- **추가 보상 / 차감**: 학급 보드에서 학생 카드를 여러 명 눌러 선택하면 아래에 보상·차감 버튼이 나타납니다.
  - 자주 쓰는 사유(예: `+3 발표 왕`, `−3 지각`)를 버튼으로 바로 적용
  - 금액과 사유를 직접 입력해 보상/차감도 가능
  - 사유와 금액은 **⚙️ 설정 → ⭐ 보상 사유**에서 자유롭게 바꿀 수 있어요.
- 잔액이 0 아래로 내려가지 않게 할지(기본), 마이너스를 허용할지 설정할 수 있습니다.
- **📜 기록**에서 모든 내역을 보고, 실수한 보상/차감/일급은 **되돌리기**할 수 있으며 CSV로 내보낼 수 있습니다.

### 2. 나만의 펫 키우기
- 학생마다 **정체불명의 알 🥚**을 하나씩 받습니다. 어떤 펫이 나올지는 부화할 때까지 비밀!
- 성장 단계: 알(0) → 아기(30) → 꼬마(100) → 청소년(250) → 전설(500 XP)
- 펫 종류 7가지: 드래곤, 공작새, 사자, 늑대, 고래, 나비, 유니콘 (각각 4단계 진화)
- 경험치를 얻는 방법
  - 보상으로 받은 화폐만큼 경험치 (설정에서 끌 수 있음)
  - 마켓에서 산 **먹이** 먹이기
  - 하루 한 번 **쓰다듬기**
- 먹이를 오래 안 주면 포만감이 줄어 펫이 배고파해요 💧
- 부화·진화하면 축하 화면이 나오고, 마켓에서 산 **꾸미기 아이템**(리본, 모자, 왕관 등)을 펫에게 씌울 수 있어요.
- **🐣 펫 마을**에서 반 전체 펫을 성장순으로 볼 수 있어요.

### 3. 학급 마켓
- 구매할 학생을 고른 뒤 상품을 사면 학생의 **가방 🎒**에 들어갑니다.
- 상품 종류
  - 🍎 **펫 먹이**: 경험치와 포만감을 올려 줌
  - 🎀 **펫 꾸미기**: 펫에게 착용
  - 🎟️ **학급 쿠폰**: 자리 선택권, 급식 먼저 먹기, 숙제 면제권 등 — 사용하면 기록에 남아요
- 상품의 이름·가격·재고(비우면 무제한)·효과는 **⚙️ 설정 → 🛒 마켓 상품**에서 바꿀 수 있습니다.

## 파일 구조

```
index.html        화면 뼈대
css/style.css     디자인
js/data.js        펫 종류, 성장 단계, 기본 직업·보상 사유·상품
js/store.js       저장, 화폐·펫·마켓 규칙
js/app.js         화면 그리기와 버튼 동작
```

## GitHub Pages로 공개하기

저장소 **Settings → Pages**에서 브랜치를 선택하고 폴더를 `/ (root)`로 지정하면 `https://<아이디>.github.io/eggboard/` 주소로 접속할 수 있어요.
(데이터는 접속한 각 브라우저에 따로 저장된다는 점에 유의하세요.)
