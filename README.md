# 🥚 에그보드 (EggBoard) — 학급 경영 웹페이지

학급 화폐로 칭찬하고, 알에서 부화한 펫을 함께 키우고, 학급 마켓에서 쇼핑하는 학급 경영 도구입니다.

- **선생님**은 학급 보드에서 일급·보상·차감을 주고, 학급 마켓을 관리합니다.
- **학생**은 선생님이 발급한 **개인 코드**로 자기 기기(휴대폰·태블릿·크롬북)에서 접속해 펫을 돌보고 마켓에서 쇼핑합니다.

## 두 가지 모드

| | 체험 모드 | 온라인 모드 |
|---|---|---|
| 설정 | 필요 없음 (`index.html`만 열면 됨) | Supabase 무료 프로젝트 연결 (아래 안내) |
| 데이터 저장 | 이 브라우저에만 | Supabase 서버 |
| 학생 개인 코드 접속 | ❌ | ✅ |
| 선생님 로그인 | 없음 | 이메일·비밀번호 |

`js/config.js`가 비어 있으면 체험 모드, Supabase 주소와 키가 들어 있으면 온라인 모드로 동작합니다.

## 주요 기능

### 1. 학급 보상 (일급 + 추가 보상 + 차감)
- **💰 오늘 일급 지급**: 1인 1역 직업별 일급(직업이 없으면 기본 일급)을 한 번에 지급. 결석생은 체크 해제, 오늘 이미 받은 학생은 표시되어 중복 지급을 막아 줍니다.
- **추가 보상 / 차감**: 학급 보드에서 학생 카드를 여러 명 눌러 선택 → 아래에 나타나는 `+3 발표 왕`, `−3 지각` 같은 버튼이나 직접 입력한 금액으로 적용.
- 잔액이 0 아래로 내려가지 않게 할지(기본), 마이너스를 허용할지 설정 가능.
- **📜 기록**에서 모든 내역 확인, 실수한 보상/차감/일급은 **되돌리기**, CSV 내보내기.

### 2. 나만의 펫 키우기
- 학생마다 **정체불명의 알 🥚**을 하나씩 받습니다. 어떤 펫이 나올지는 부화할 때까지 비밀!
- 성장 단계: 알(0) → 아기(30) → 꼬마(100) → 청소년(250) → 전설(500 XP), 펫 종류 7가지.
- 경험치: 보상으로 받은 화폐만큼(설정에서 끌 수 있음) + 마켓 **먹이** + 하루 한 번 **쓰다듬기**.
- 먹이를 오래 안 주면 배고파해요 💧. 부화·진화하면 축하 화면이 나오고, **꾸미기 아이템**을 씌울 수 있어요.
- **펫 마을**에서 반 전체 펫 구경 (학생 화면에서는 친구들의 잔액은 보이지 않아요).

### 3. 학급 마켓 (선생님이 관리)
**🛒 학급 마켓** 탭에서 선생님이 마켓 전체를 관리합니다.
- **🛍️ 진열대**: 학생 대신 구매하기
- **🛠️ 상품 관리**: 상품 추가·삭제, 이름·가격·재고(비우면 무제한)·효과 수정
- **🟢 마켓 열기/닫기**: 닫으면 학생은 구경만 할 수 있어요 (선생님은 대신 구매 가능)
- **📬 쿠폰 요청**: 학생이 쿠폰(자리 선택권, 숙제 면제권 등) **사용 요청**을 하면 여기 쌓이고, 선생님이 **승인**하면 사용 처리, **거절**하면 학생 가방으로 돌아갑니다.
- **🧾 판매 내역**: 누가 언제 무엇을 샀고 썼는지

상품 종류: 🍎 펫 먹이(경험치·포만감) · 🎀 펫 꾸미기(착용) · 🎟️ 학급 쿠폰(교사 승인 후 사용)

### 4. 학생 개인 코드 (온라인 모드)
- 학생을 등록하면 6자리 개인 코드(예: `K7QX3M`)가 자동 발급됩니다. 헷갈리는 0/O, 1/I는 쓰지 않아요.
- **⚙️ 설정 → 👩‍🎓 학생·코드 → 🖨️ 코드표 인쇄**로 잘라서 나눠 줄 수 있는 코드 카드를 인쇄하세요.
- 학생은 사이트에 들어가 **🙋 학생** 탭에서 코드를 입력하면 자기 계정으로 들어갑니다.
  - 🐣 내 펫: 펫 돌보기(쓰다듬기·먹이기·이름 짓기·꾸미기), 잔액, 가방, 최근 기록
  - 🛒 마켓: 자기 잔액으로 직접 구매, 쿠폰 사용 요청
  - 🏡 펫 마을 / 📜 내 기록
- 코드가 친구에게 알려졌다면 학생 표에서 **재발급**을 누르세요. 예전 코드는 바로 막힙니다.

## 온라인 모드(Supabase) 설정 — 처음 한 번만, 약 10분

1. **Supabase 프로젝트 만들기**
   [supabase.com](https://supabase.com)에 가입 → **New project** (지역은 `Northeast Asia (Seoul)` 추천). 무료 요금제로 충분합니다.
2. **데이터베이스 만들기**
   왼쪽 메뉴 **SQL Editor** → 새 쿼리에 이 저장소의 [`supabase/schema.sql`](supabase/schema.sql) 내용을 **전부 붙여넣고 Run**.
   (나중에 에그보드를 업데이트할 때도 같은 파일을 다시 실행하면 됩니다. 기존 데이터는 지워지지 않아요.)
3. **이메일 인증 설정 (선택)**
   **Authentication → Sign In / Providers → Email**에서 *Confirm email*을 끄면 가입 즉시 로그인됩니다.
   켜 두면 가입 후 받은 메일의 링크를 눌러야 로그인할 수 있어요. 이때는 **Authentication → URL Configuration**의 *Site URL*을 에그보드 주소로 바꿔 두세요.
4. **연결 정보 넣기**
   **Project Settings → API**(또는 **Connect** 버튼)에서 *Project URL*과 *anon public* 키를 복사해 `js/config.js`에 넣습니다.
   ```js
   window.EGGBOARD_CONFIG = {
     supabaseUrl: 'https://abcdefgh.supabase.co',
     supabaseAnonKey: 'eyJhbGciOi...',
   };
   ```
   > anon 키는 공개되어도 괜찮은 키예요(학생이 직접 데이터를 고칠 수 없도록 데이터베이스가 막고 있어요). **service_role 키는 절대 넣지 마세요.**
5. **사이트 공개 (GitHub Pages)**
   저장소 **Settings → Pages**에서 브랜치를 고르고 폴더를 `/ (root)`로 지정하면 `https://<아이디>.github.io/eggboard/` 주소가 생깁니다.
6. **선생님 계정 만들기**
   사이트에서 **🧑‍🏫 선생님 → 처음이에요 · 교사 계정 만들기**. 처음 로그인하면 학급과 기본 상품이 자동으로 만들어집니다.

> Supabase 무료 프로젝트는 일주일 넘게 아무도 접속하지 않으면 일시 정지될 수 있어요. 방학 뒤에는 Supabase 대시보드에서 **Restore**를 눌러 다시 켜 주세요.

### 보안은 어떻게 되나요?
- 선생님은 Supabase 계정으로 로그인하고, **자기 학급 데이터만** 볼 수 있어요 (Row Level Security).
- 학생은 계정 없이 코드로 들어오며 **데이터베이스 표에 직접 접근할 수 없어요.** 코드로 확인되는 몇 가지 동작(내 정보 보기, 구매, 먹이기, 쓰다듬기, 이름 짓기, 쿠폰 요청)만 할 수 있고, 잔액을 직접 바꾸는 방법은 없습니다. 잔액 부족·품절·하루 한 번 쓰다듬기 같은 규칙도 모두 서버에서 검사합니다.
- 반 친구의 잔액과 가방은 학생에게 보이지 않아요.

## 파일 구조

```
index.html           화면 뼈대
css/style.css        디자인 (인쇄용 코드표 포함)
js/config.js         Supabase 연결 설정 (비우면 체험 모드)
js/data.js           펫 종류, 성장 단계, 기본 직업·보상 사유·상품
js/store.js          체험 모드 저장소와 화폐·펫·마켓 규칙
js/backend.js        체험/교사/학생 데이터 계층 (Supabase 호출)
js/app.js            화면 그리기와 버튼 동작
supabase/schema.sql  온라인 모드 데이터베이스 (표, 보안 정책, 서버 함수)
```
